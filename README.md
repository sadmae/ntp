# КП НТП

Материалы по Комплексной программе научно-технического прогресса.

Методика СТОНХ хорошо инвентаризирует технологии и слабо прогнозирует: в ней нет обратной реакции рынка. Как замкнуть контур на рядах НСК и Нацбанка, написано в [docs/zamknutyy-kontur.md](docs/zamknutyy-kontur.md).

Первый экран — три вопроса: что уже произошло, что будет со швейкой, вырастет ли доля своих лекарств. Отдельные вкладки разбирают золото, стройку и сезонность урожая: полугодовой запрет импорта и запрет экспорта не получают цену в сомах и не отдают запрещённый экспорт фермеру, пока не названо, кто его удержит. Пустой коэффициент расчёт останавливает: [dashboard/index.html](dashboard/index.html). Расчёты живут в `dashboard/model.js`, проверка — `node --test dashboard/model.test.js`.
